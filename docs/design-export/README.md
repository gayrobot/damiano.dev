# Design export

A hand-off bundle for Claude Design. Start with `BRIEF.md`. `source/` is a copy (Astro files end in `.txt` so the type check ignores them) of the current design files (`src/styles/`, `src/components/`, `src/layouts/Base.astro`) and `screens/` shows the baseline. These are snapshots; the live files in `src/` are the source of truth.
