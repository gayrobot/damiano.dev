# damiano.dev

Personal site at damiano.dev, and the harness that lets an agent change it safely.

Built with [Astro](https://astro.build) as a static site. See [`docs/handoff.md`](docs/handoff.md) for the decisions and milestones.

## Local development

```sh
npm install
npm run dev      # local dev server
npm run check    # type check
npm run build    # static output in dist/
```
