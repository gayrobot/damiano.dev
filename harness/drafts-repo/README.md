# damiano.dev drafts

Private. Musings and project write-ups are drafted here, then promoted to the public site by PR.

- Drafts live in `musings/` and `projects/`, using the same front matter as the public site's schema (see `musings/_template.md`).
- To publish: set `approved: true` (musings), then run **Actions → Promote → Run workflow** with the file path, for example `musings/my-essay.md`.
- That opens a PR in `gayrobot/damiano.dev`. The privacy gate, content lint and build run there. Skylar reviews and merges.

Setup, once: see `docs/drafts-flow.md` in the public repo.
